🩺 Skin Disease Detection — Deep Learning & Computer Vision
Deployed on Render Domain: Computer Vision (Educational Prototype)
Educational prototype only; not intended for medical diagnosis.
# Project Overview & Pipeline

Skin Disease Detection is a deep learning web application that classifies skin lesion conditions into categorical classifications. The pipeline consists of: (1) Image Preprocessing: user-uploaded images are resized to the expected input dimensions (224×224), scaled, and normalized; (2) Model Inference: a MobileNet architecture implemented in TensorFlow extracts visual features and applies transfer learning weights; (3) Classification & Interface: predictions are returned to the user via a Python Flask web interface displaying top predicted categories and confidence scores.

# Evaluation & Metrics

Model performance was evaluated on a held-out test split using Categorical Accuracy and loss curves during validation. Because this is an academic and educational exploration of deep learning architectures, all outputs are strictly exploratory.

🚨 Multi-Agent Disaster Management Simulator (Disaster-OS)
Deployed on Vercel Domain: Multi-Agent Systems & Simulation Engine
# System Architecture

Disaster-OS simulates multi-agent coordination during environmental disaster incidents. Agents represent detection units, incident responders, and resource dispatchers that exchange messages and track events in a simulated environment. The system records incident states, logs interaction timelines, and provides API endpoints implemented with FastAPI to serve simulation telemetry to the frontend.

# Evaluation Metrics

The simulator benchmarks emergency response effectiveness against simulated baselines using three key metrics: (1) Detection Accuracy: the ratio of correctly recognized hazard events to total simulated occurrences; (2) Detection Time: the latency in simulation ticks from incident generation to agent alert; (3) False-Positive Rate: the frequency of false alerts generated under noisy environmental conditions.
